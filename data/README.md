# CrossCut Salon Website

A responsive static website project developed as part of my web development learning journey.

## Project Description

CrossCut Salon is a salon website prototype designed to demonstrate modern frontend web development fundamentals.

The project currently includes:

- Semantic HTML
- Traditional CSS
- Responsive design
- Flexbox
- CSS Grid
- JavaScript fundamentals
- DOM manipulation
- Event listeners
- Mobile navigation
- Booking form
- Client-side form validation
- JSON data
- Fetch API
- Dynamic service rendering

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- Fetch API
- Git
- GitHub
- Vercel

## Current Features

### Navigation

Responsive navigation with a mobile burger menu.

### Services

Salon services are loaded from a local JSON file and rendered dynamically using JavaScript.

### Booking Form

The booking form includes client-side validation for:

- Customer name
- Mobile number
- Service
- Appointment date
- Appointment time

### Responsive Design

The website is designed to work on:

- Desktop
- Tablet
- Mobile
